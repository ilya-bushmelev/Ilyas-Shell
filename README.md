# 💚 Ilya's:Shell 🐚

**Модульная оболочка для терминала, написанная на Python 3.14**

---

## ✨ Особенности

- **Две оболочки в одном флаконе**:  
  - `ilya's:cmd_` — первая версия, простая и быстрая. Останется легендой навсегда. 
  - `💚 Ilya's:Shell 🐚` — улучшенная, модульная, с поддержкой пользовательских команд.

- **Команды**:
  - `kill <цель>` — убить кого-нибудь. Убивать мёртвого нельзя.
  - `revive <цель>` — воскресить с драматической задержкой.
  - `dead_list` — список убитых.
  - `whoami` — узнать юзернейм (с пасхалкой для создателя).
  - `version` — версия оболочки.
  - `help` — показать список команд.
  - `exit` / `quit` / `break` — выйти из оболочки.
  - `calc` / `calculator` / `calc1` — калькулятор (в отдельном `calc1.py`).
  - `pif` / `pifagor` — решатель теоремы Пифагора (в отдельном `pifagor.py`).
  - `rng` / `random` / `randomizer <min> <max>` — генератор случайных чисел.
  - `guess <максимум>` — игра «угадай число».
  - `echo <текст>` — вывести текст.
  - `binary [-e/-d] <число>` — перевод в двоичную систему и обратно.
  - `hex [-e/-d] <число>` — перевод в шестнадцатеричную систему и обратно.
  - `eval <код>` — вызов `eval()` (отключён по умолчанию, включается в конфиге).
  - `date` — показать текущее время и дату.
  - `cd <путь>` — перейти в директорию.
  - `pwd` — показать текущий путь.
  - `ls <путь>` — список файлов в директории.
  - `touch <файл>` — создать пустой файл.
  - `mkdir <путь>` — создать директорию.
  - `rm <файл>` — удалить файл.
  - `rmdir <путь>` — рекурсивно удалить директорию (с подтверждением).
- **Сайт про Ilya's:Shell**

    [Ссылка на сайт](https://ilya-bushmelev.github.io/Ilyas-Shell)

- **Пользовательские команды**:  
  Добавь свои функции в `configShell.py` — и они появятся в оболочке. 
  Гайд по добавлению команд находится ниже.
  
  **ВАЖНО!:** Пользовательские команды НЕ работают в ilya's:cmd.

- **Цветной вывод**:  
  ANSI-цвета делают общение с терминалом ярким и живым.
  *их кстати можно изменить в конфигах :)*

- **История команд**:  
  Все введённые команды сохраняются в `.history_file`.

## 📦 Установка
### После версии v1.2.1
- Перейди в [последний релиз](https://github.com/ilya-bushmelev/Ilyas-Shell/releases/latest).
- И скачай по инструкции в релизе.
### До версии v1.2.1 (Arch)
- Перейди в [последний релиз](https://github.com/ilya-bushmelev/Ilyas-Shell/releases/latest).
- Установи пакет .tar.zst
- Установи
```bash
sudo pacman -U ~/Путь/До/ilyasshell-1.2-1-any.pkg.tar.zst 
```
- Пользуйся:
```bash
ilyasshell # для Ilya's:Shell
ilyascmd # для ilya's:cmd_
```

### Почему нет других версий?
Над этим проектом работает один человек, сборка пакетов для разных дистрибутивов это трудоёмкая задача. Так как времени для этого я не уделяю, пакет, соответствено, будет только для Arch Linux. Если желаете помочь в сборке пакетов, то свяжитесь со мной. 
### Почему после версии v1.2.1 перестали выходить пакеты?
Стандартный pacman-пакет все кидает в /usr/share, соответствено если пользователь захочет изменить конфиг или саму оболочку ему придётся лезть туда с правами root/sudo, что не есть хорошо. Клонирование релиза решит эту проблему

## 🚀 Быстрый запуск

### Локально:
  ```bash
    ln -s ~/путь/к/Ilyas-shell/IlyasShell.py ~/.local/bin/ilyasshell
  ```
### Для всех пользователей (нужны права sudo):
  ```bash
    sudo ln -s ~/путь/к/Ilyas-shell/IlyasShell.py /usr/bin/ilyasshell
  ```

## 🧑‍💻 Импорт вручную

### Чтобы импортировать одну из двух оболочек скопируй в самый верх кода:
  ```python
  import IlyasShell as ish # или ilyascmd_main 
  ```
### Использование в коде:
  ```python
  # без аргументов
  ish.whoami()
  # с аргументами
  ish.revive(['вадим'])
  ```

## Гайд по добавлению пользовательcких команд в конфиг
### В `configShell.py` найди класс `USER_COMMANDS`:
  ```python
  class USER_COMMANDS:
    enabled = False

    # -- Команды --
    def chizhik_says(arg):
        text = ' '.join(arg)
        print(f"Чижик говорит: {text}")

    # -- Ссылки на команды --
    list_with_args = {
        'chizhik_says': chizhik_says
    }; list_ = {
        # пока здесь пусто ;(
      }
  ```
### Для добавления собственной команды ее надо поместить в функцию под коментарием `# -- Команды -- `
#### Без аргументов:
```python
    def my_command():
      print('Это моя пользовательская команда!')
```
#### С аргументами:
```python
    def my_age(arg):
      age = ' '.join(arg) # Нужно для превращения списка в строку
      # Если надо только первый аргумент
      age = arg[0]
      print(f'Мне {age} лет!')
```
### Теперь надо добавить ссылку на команду
#### Без аргументов:
```python
  list_ = {
    #'команда для вызова':название функции для вызова
    'my_command':my_command
  }
```
#### С аргументами:
```python
  list_with_args = {
    'my_age':my_age
  }
```
### Самое важное и сложное:
#### Заменить значение `enabled` на `True`:
```python
  enabled = True
```
#### Если надо отключить можно заменить значение на что угодно:
```python
  enabled = False
```
### Сохрани конфиг и проверяй

## 🐦 Чижик и Пыжуля

- **Оболочка создавалась под присмотром двух волнистых попугаев**:

    - Чижик — зелёный, шумный, наглый, но прикольный. Главный тестировщик.

    - Пыжуля — жёлтая, мудрая, тихая, иногда тоже орущая. Вдохновитель.

## 📈 С чего всё начиналось.
Начался этот путь с мысли "А что если я сделаю оболочку похожую на bash?" Тогда разработка началась с уже ныне архивной оболочки ilya's:cmd_. Если я правильно помню то первыми командами были: `kill`,`revive`,`whoami`. Тогда команды не могли принимать аргументы, вместо этого просто пишешь команду и она запрашивать цель (сейчас кстати то же самое доступно в обоих оболочках, но лучше аргументы). Потом мне понравилась идея модульной оболочки, и я почти с нуля сделал Ilya's:Shell, а далее и репозиторий и этот README тоже.
